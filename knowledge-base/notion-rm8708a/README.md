# RM8708A Notion archive

This directory is a local, sanitized snapshot of the public Notion page
[`RM8708A Supercapacitor controller`](https://merciful-iguanodon-c69.notion.site/RM8708A-Supercapacitor-controller-307fa7e594d880509271ff5a7605a5f0).

- [`page.md`](page.md) preserves the page content in reading order.
- [`manifest.json`](manifest.json) records source identifiers, file sizes, and SHA-256 checksums.
- [`assets/`](assets/) contains the six embedded images, the social preview, the published firmware attachment, and two externally embedded TI PDFs.

The snapshot was captured from the anonymously accessible public-page API on
2026-09-04. Temporary Notion signed URLs, workspace permissions, user IDs, and
other unrelated internal metadata are intentionally not retained.

The page also links to project files that already live at the repository root:

- [`3D_4loko_2026-02-15.step`](../../3D_4loko_2026-02-15.step)
- [`ProPrj_supercap v0.1_2026-02-15.epro`](../../ProPrj_supercap%20v0.1_2026-02-15.epro)
- [`Calibration Script.ipynb`](../../Calibration%20Script.ipynb)

`assets/test.elf` is an untrusted binary snapshot. It has been archived but was
not executed.
