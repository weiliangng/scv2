SCV2 supercapacitor controller

SCV2 controls a robot supercapacitor bank and reports its operating state.

Purpose

Manage power flow while applying voltage, fault, command-timeout, and switching protections.

Features

  • Referee UART and CAN control inputs
  • CAN and UART telemetry
  • USB command-line interface
  • Desktop telemetry dashboard
  • Capacitor health monitoring
